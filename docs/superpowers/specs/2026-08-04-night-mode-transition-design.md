# 设计规格：四角灯泡渐进熄灯过渡到黑夜模式

日期：2026-08-04
项目：no.4-midinmy（Vue 3 + Vite + gsap）

## 1. 背景与目标

当前页面只在左上、右上放置 2 个灯泡，两个都破碎后直接给 `<html>` 添加 `dark-mode` 类并播放黑夜刀光加载动画，切换生硬。

目标：将"两灯泡全碎 → 硬切黑夜"改为"四角灯泡渐进熄灭 → 平滑过渡到黑夜"，使黑夜切换更流畅，且最终暗色贴近黑夜加载动画的颜色。

## 2. 需求要点（已与用户确认）

1. **布局**：屏幕四角各放 1 个灯泡（左上/右上/左下/右下），替换现有 2 个。
2. **光源语义**：每个灯泡 = 一个光源，活着时从所在角落向页面投射光；碎了，光源熄灭。
3. **分区变暗（手电效果）**：某角灯泡破碎 → 该象限从角落向外"暗下去"，边缘柔和，模拟手电熄灭。
4. **叠加暗化**：每多碎一个灯泡，相邻的已暗区域进一步变暗，逐步逼近黑夜加载动画的颜色（深蓝黑 `#0c0c1a → #050512`）。
5. **收尾**：四角全碎、页面暗到最深后，**保留原有黑夜刀光切换动画**，随后进入完整黑夜模式（`dark-mode` 类）。
6. **实现方案**：方案 A —— CSS 光照遮罩层（全屏 fixed 遮罩 + 4 个径向渐变光源，CSS 变量控制暗度）。

## 3. 架构与数据流

**结构**（全部在现有文件内，**不新增文件**）：

```
App.vue
  ├── script: 4 个角落布尔状态 (TL/TR/BL/BR) + 暗度计算函数
  ├── template:
  │     ├── 4 × <Light> 灯泡（四角定位，替换现有 2 个）
  │     ├── 光照遮罩层 <div class="light-mask">（夜晚底色 + 4 个光斑）
  │     └── 其余原有结构不变
  └── style: .light-mask 及相关样式

Light.vue —— 零改动，继续只负责"灯泡破碎动画 + emit('broken')"
```

**数据流**：

```
App.vue（4 个布尔: cornerTL/TR/BL/BR）
  ├── 4 × <Light> 灯泡 ── broken 事件 ──> 标记该角为 true
  ├── <div class="light-mask"> ← 根据 broken 状态渲染暗度
  └── 4 个全碎 ──> 触发原有黑夜切换流程（隐藏游戏 + dark-mode + 刀光动画）
```

## 4. 暗度模型（核心计算）

- 每破坏一个灯泡：该角暗度 `0 → 1`（光源熄灭），同时**全局基线暗度 +0.25**。
- 每个角落的最终暗度 = `max(自身暗度, 全局基线)`，实现"相邻已暗区域跟着更暗"。
- 四角全碎：所有角落暗度 = 1，遮罩整体呈黑夜色。
- 遮罩上所有暗度变化用 **CSS transition（约 0.8s）** 驱动，平滑渐变。

| 已碎灯泡数 | 全局基线 | 效果 |
|---|---|---|
| 0 | 0 | 全屏白天 |
| 1 | 0.25 | 该角暗下，整体微微变暗 |
| 2 | 0.5 | 两角暗下，已暗区域加深 |
| 3 | 0.75 | 三角暗下，全屏接近夜晚 |
| 4 | 1 | 全屏黑夜色，触发刀光动画 |

## 5. 遮罩层视觉实现

```html
<!-- 光照遮罩：夜晚底色 + 4 个光源光斑 -->
<div class="light-mask" :style="maskStyle">
  <div class="night-base" :style="{ opacity: baseDark }" />
  <div class="spot spot-tl" :style="{ opacity: 1 - dark.tl }" />
  <div class="spot spot-tr" :style="{ opacity: 1 - dark.tr }" />
  <div class="spot spot-bl" :style="{ opacity: 1 - dark.bl }" />
  <div class="spot spot-br" :style="{ opacity: 1 - dark.br }" />
</div>
```

**视觉层次**（从下到上）：
1. **夜晚底色层 `.night-base`**：纯深蓝黑渐变 `linear-gradient(180deg, #0c0c1a, #050512)`（与黑夜加载动画同色），opacity = 全局基线暗度。
2. **光源光斑层 `.spot`**：每个是全屏 `radial-gradient(circle at 对应角落, 亮光色, transparent 60%)`，opacity = `1 - 该角暗度`。
   - 灯泡亮着 → 光斑 opacity 1（照亮该象限，页面呈现白天）。
   - 灯泡碎了 → 光斑 opacity → 0（光源熄灭，露出夜晚底色，区域暗下去）。

**过渡动画**：
- 所有 opacity 变化加 `transition: opacity 0.8s ease`。
- 破碎瞬间：该角光斑淡出 + 夜晚底色浮现 → "手电从角落向外熄灭"的柔和过渡。
- 相邻区域：因全局基线 +0.25，夜晚底色整体加深，已暗区域更暗。

**混合模式**：光斑用 `mix-blend-mode: screen` 叠在夜晚底色之上，亮光色（暖黄 `#FFE066`）与底色混合出自然光照，四角光斑叠加区域更亮——模拟多光源真实叠加。

**黑夜收尾**：全碎后暗度全 1 → 遮罩全屏黑夜 → 触发原有流程（隐藏游戏 + `dark-mode` 类 + 刀光动画覆盖），遮罩随之隐藏。

## 6. 黑夜收尾与边界情况

**黑夜收尾流程**（四角全碎时）：
1. 遮罩暗度到达全 1，全屏呈现黑夜色。
2. 触发现有流程：隐藏游戏（`gameVisible = false`）、`dark-mode` 类、播放黑夜刀光加载动画。
3. 刀光动画播完（`onTransitionDone`）→ 进入完整黑夜模式，隐藏遮罩层。

**切回白天**（`onSwitchToLight`，由 Dark_more 的月亮/按钮触发）：
- 4 个灯泡状态全部重置为 false，`bulbKey++` 重建灯泡。
- 遮罩全部暗度归零（过渡回白天），重新显示。
- 游戏恢复。

**边界情况**：

| 场景 | 处理 |
|---|---|
| 灯泡破碎动画进行中（isBreaking） | 不可再次点击（现有逻辑已防抖） |
| 遮罩过渡中又碎了另一个灯泡 | CSS transition 自动衔接，无需特殊处理 |
| 灯泡已碎但页面仍白天（<4 个） | 遮罩按暗度模型呈现部分夜晚效果，页面其余部分正常 |
| 窗口缩放 | 光斑用百分比/`cover` 定位，天然自适应 |

## 7. 性能

纯 CSS opacity 过渡 + 4 个渐变层，无 JS 每帧计算，对性能无压力。

## 8. 非目标（明确不做）

- 不做 Canvas 真实光照渲染（方案 B）。
- 不做 SVG 滤镜光效（方案 C）。
- 不改变 Light.vue 组件的破碎交互逻辑。
- 不改变黑夜刀光加载动画本身。
