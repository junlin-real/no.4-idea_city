# HyperCube Vue 组件开发计划

## 需求概要

基于参考项目 `HyperCube-main`（p5.js 渲染的四维超立方体线框），创建 Vue 3 组件 `HyperCube.vue`，放置于首页 hero 区域左侧，控制面板位于超立方体正下方。

## 核心功能

| # | 功能 | 控制方式 | 实现说明 |
|---|------|---------|---------|
| 1 | **颜色配置** | 单个滑块 | 合并原 HSB 三个滑块为一个色相滑块（0-360），饱和度/亮度固定为最佳值 |
| 2 | **外层立方体转速** | 滑块 | 控制 w=-1 层（外层）的 ZW 旋转速度，独立于内层 |
| 3 | **内层立方体转速** | 滑块 | 控制 w=+1 层（内层）的 ZW 旋转速度，独立于外层 |
| 4 | **透视强度** | 滑块 | 控制 stereographic projection 的 `distance` 参数（范围 1.2~4） |
| 5 | **间距** | 滑块 | 控制内外两层在 w 轴上的距离因子（范围 0.5~3，默认 1.0） |

## 技术方案

### 废弃 p5.js，改用纯 Canvas 2D + 自写数学

**理由：**
- p5.js 文件 11 万行，为 Vue 组件引入太重
- 参考项目只用了 p5.js 的 WEBGL canvas、`orbitControl()`、基础绘图 API
- 所有 4D 数学（旋转矩阵、投影、矩阵运算）都是手写的，不依赖 p5.js
- 改用 Canvas 2D 后体积更小、更 Vue 化、不需要额外依赖

### 渲染管线

```
16个4D顶点 (±1, ±1, ±1, ±1) × spacing_factor
        │
        ▼
  内层顶点(w=+spacing) ──→ ZW旋转(内层角度) ──┐
  外层顶点(w=-spacing) ──→ ZW旋转(外层角度) ──┤
        │                                      │
        ▼                                      ▼
  Stereographic Projection (distance 可调)
        │
        ▼
  3D旋转（鼠标拖拽的轨道旋转 + 固定视角）
        │
        ▼
  Perspective Projection (3D→2D)
        │
        ▼
  Canvas 2D 绘制线段
```

### 关键技术点

1. **4D→3D 投影**：`w_scale = 1 / (distance - v.w)`
   - `distance` 越小 → 透视越强 → 近大远小明显
   - `distance` 越大 → 透视越弱 → 接近正交投影

2. **间距调整**：将顶点 w 坐标从固定 ±1 改为 `±spacing_factor`
   - `spacing_factor = 1` 保持原始效果
   - `< 1` 两层靠近，`> 1` 两层远离

3. **内外层独立转速**：
   - 外层：`outer_angle += 0.01 * outer_speed` → 只旋转 w=-spacing 的 8 个顶点
   - 内层：`inner_angle += 0.01 * inner_speed` → 只旋转 w=+spacing 的 8 个顶点

4. **鼠标轨道控制**：监听 mousedown/mousemove/mouseup + wheel 事件
   - 拖拽 → 旋转视角（theta, phi）
   - 滚轮 → 缩放

5. **颜色**：HSL 色彩空间，单一色相滑块（0-360），固定 S=100%, L=50%

## 文件变更

### 新建文件

**`src/components/HyperCube.vue`** — Vue 3 组件，约 350 行

结构：
- `<template>`：Canvas 画布 + 控制面板（5个滑块），使用 Vue scoped 样式
- `<script setup>`：核心逻辑
  - `Vector4D` 类
  - 4D 顶点定义（支持 spacing 因子）
  - ZW 旋转矩阵生成
  - 4D→3D stereographic projection
  - 3D 旋转矩阵（X/Y 轴，基于鼠标拖拽）
  - 3D→2D perspective projection
  - Canvas 绘制线框
  - `requestAnimationFrame` 驱动渲染循环
  - 响应式状态：`hue`, `outerSpeed`, `innerSpeed`, `distance`, `spacing`
  - 鼠标事件处理（轨道旋转 + 缩放）
- `<style scoped>`：Canvas 容器样式、控制面板样式

### 修改文件

**`src/App.vue`**：在 hero 区域（第一个 section）引入 HyperCube 组件

```vue
<!-- 在 hero section 中添加 -->
<div class="hero-content">
  <HyperCube />
  <div class="hero-text">...</div>
</div>
```

将 hero 区域改为 flex 布局，HyperCube 在左侧，文字内容在右侧。

## 验证方案

1. `npm run dev` 启动开发服务器
2. 打开浏览器，确认首页 hero 区域左侧显示旋转的超立方体
3. 测试每个滑块：
   - 拖动色相滑块 → 线框颜色在彩虹色间变化
   - 拖动外层转速 → 外层立方体旋转加速/减速
   - 拖动内层转速 → 内层立方体旋转加速/减速（可与外层不同步）
   - 拖动透视强度 → 远近透视效果变化
   - 拖动间距 → 内外两层距离变化（拉到最小时两层几乎重合，最大时明显分离）
4. 鼠标拖拽超立方体 → 视角自由旋转
5. 滚轮 → 缩放
6. 确认响应式布局在窗口缩放时正常
