# 武士刀加载动画优化方案 v2

## 目标

重写 `src/components/loding.vue`，基于用户反馈进行以下改进：

1. **动画时长 ×5** — 全部阶段时长扩大 5 倍，总长约 11.5s
2. **幕布切口流水效果** — 上下遮罩切开边缘各自流出粘稠墨水，模拟液体流下
3. **火花沿刀身产生** — 火花粒子从刀刃全长散落（不只是尖端）
4. **墨滴固定位依次出现** — 切口路径上采样固定点位，墨滴依次弹出
5. **墨滴水渍融合扩散** — 斩击完成后每个墨滴各自扩散为圆形，融合铺满全屏

## 1. 火花沿刀身 — 刀身焰火

### 改动要点
- 不只从刀尖生成粒子，而是沿刀身采样 4-6 个点（从刀尖到刀柄均匀分布）
- 每个采样点每帧生成 1-2 个火花
- 粒子更大（3-8px），生命周期匹配 5x 动画（1.5-3s）
- 颜色更多样：金、橙、红、白，模拟真实火焰层次
- CSS 动画：`spark-fly` 延长到粒子 life 时长，带旋转

### 刀身采样点计算
```js
function getBladePoints(rect) {
  const tipY = rect.top + rect.height * 0.1
  const midY = rect.top + rect.height * 0.5
  const baseY = rect.top + rect.height * 0.85
  const x = rect.left + rect.width * 0.5
  return [
    { x, y: tipY },
    { x, y: tipY + (midY - tipY) * 0.5 },
    { x, y: midY },
    { x, y: midY + (baseY - midY) * 0.5 },
    { x, y: baseY },
  ]
}
```

## 2. 幕布切口 — 粘稠流水效果

### 设计思路
上下遮罩的 clip-path 切开后，切口边缘形成一条斜线。从这条斜线：
- **上遮罩底边**：墨汁向下流淌（像粘稠液体挂在切口边缘滴落）
- **下遮罩顶边**：墨汁同样向下滴落

### 实现
在 `onUpdate` 中，利用切口当前坐标 (`cutX%`, `cutY%`)，沿切口线每隔一段距离生成一个"流水滴"：
- 水滴从切口边缘位置起始，向下缓慢流动
- 水滴较大（6-14px），不透明（0.6-0.9）
- 动画时长 2-4s（匹配慢速节奏）
- 使用 `@keyframes ink-flow`：先缓慢变形拉长（粘稠感），再断开滴落
- 水滴有连接感 — 相邻水滴几乎同时出现，形成"水帘"效果

### 代码要点
```js
function spawnFlowDrops(cutXPercent, cutYPercent, maskDownXPercent) {
  // 每隔 5% 的切口长度生成一个水滴
  // 上遮罩边缘：x 从 0% 到 cutXPercent，y 从 0% 到 cutYPercent
  // 下遮罩边缘：x 从 maskDownXPercent 到 cutXPercent，y 从 100% 到 cutYPercent
  const steps = 8
  for (let i = 0; i < steps; i++) {
    const t = i / steps
    // 上边缘
    flowDrops.push({
      id: flowId++,
      x: (t * cutXPercent / 100) * innerWidth,
      y: (t * cutYPercent / 100) * innerHeight,
      from: 'upper',
      size: 6 + Math.random() * 8,
      delay: i * 0.05,
    })
    // 下边缘
    const dx = cutXPercent - maskDownXPercent
    flowDrops.push({
      id: flowId++,
      x: ((maskDownXPercent + t * dx) / 100) * innerWidth,
      y: ((100 - (100 - cutYPercent) * t) / 100) * innerHeight,
      from: 'lower',
      size: 6 + Math.random() * 8,
      delay: i * 0.05,
    })
  }
  // 限流上限 120
}
```

## 3. 固定墨滴 + 水渍融合扩散

### 阶段 A：墨滴依次出现（斜劈阶段）
- 在 `onUpdate` 中每 N 帧采样切口位置，记录为固定墨滴坐标
- 存入 `inkBlots` 数组
- 墨滴在斜劈结束后全部就位（约 15-25 个墨滴沿切口线分布）

### 阶段 B：墨滴各自扩散（墨染阶段，4s）
- 斜劈结束后，GSAP 追加新的时间线段
- 每个墨滴（inkBlot）渲染为一个 `<div>`，初始 `transform: scale(0)`
- 各墨滴同时开始从 `scale(0)` 扩散到 `scale(2-4)`（足以覆盖全屏的大小）
- 不同墨滴略有延迟（stagger 0.05-0.1s），错落扩散
- 墨滴颜色深蓝黑 `#060d1a`，背景为 `radial-gradient`
- 多个扩散圆重叠区域自然融合为同一深色

### 代码结构
```js
const inkBlots = reactive([])  // 记录固定墨滴坐标
let blotId = 0
let blotSampleCounter = 0

// 在 onUpdate 中采样
function sampleBlot(cutX, cutY) {
  blotSampleCounter++
  if (blotSampleCounter % 6 !== 0) return  // 每6帧采样一次
  inkBlots.push({
    id: blotId++,
    x: (cutX / 100) * innerWidth,
    y: (cutY / 100) * innerHeight,
    scale: 0,
  })
}

// 墨染阶段 GSAP：对每个墨滴做 stagger 扩散
// 在斜劈结束时，所有 inkBlots scale 为 0
// GSAP stagger 依次将它们扩散到 scale 大值
```

### 模板
```html
<div class="ink-blot-container">
  <span
    v-for="b in inkBlots" :key="b.id"
    class="ink-blot"
    :style="{
      left: b.x + 'px', top: b.y + 'px',
      transform: `translate(-50%, -50%) scale(${b.scale})`,
    }"
  />
</div>
```

### 样式
```css
.ink-blot {
  position: absolute;
  width: 250px; height: 250px;
  background: radial-gradient(circle, #060d1a 40%, #0a1025 70%, transparent 100%);
  border-radius: 50%;
  opacity: 0.85;
  will-change: transform;
}
```
